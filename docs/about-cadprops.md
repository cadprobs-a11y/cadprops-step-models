# About CADProps

This [step file viewer](https://www.cadprops.com/) provides browser-based CAD and mesh inspection tools. This repository offers downloadable parts that can be used in other CAD software as well as CADProps.

## Useful tasks

- [View STEP and STP models](https://www.cadprops.com/tools/step-viewer/): rotate, zoom, examine structure and inspect supported geometry.
- [Check CAD dimensions](https://www.cadprops.com/tools/cad-dimensions/): read source-axis extents and available local measurements.
- [Calculate CAD solid volume](https://www.cadprops.com/tools/cad-volume-calculator/): inspect valid closed geometry and its reported units.
- [Inspect surface area](https://www.cadprops.com/tools/cad-surface-area/): examine areas calculated from CAD faces.
- [Compare CAD files](https://www.cadprops.com/tools/compare-cad-files/): inspect revisions using the comparison modes supported by the inputs.

Viewing and measuring can start without an account. Conversion, account storage and creating share links require signing in. Files are uploaded for server processing; read the [privacy information](https://www.cadprops.com/privacy/) before uploading a confidential design and the [accuracy notes](https://www.cadprops.com/accuracy/) before using numerical results.

CADProps curates the community parts in this repository and creates the original parts marked CC0. Upstream authors retain credit for their models.
